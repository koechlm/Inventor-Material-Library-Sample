# Inventor-Material-Library-Sample

This sample includes Inventor default materials (as of Inventor 2021) and added definitions using numbers and designations, e.g., "1.8519 31CrMoV9". 
Material groups enhance navigation and usability. All groups follow a bilingual naming convention: English|German, e.g., "Steel—Nitriding Steel|Nitrierstähle."
Fastener Strength Categories complement the library. A preview is posted to this repository's wiki page.
